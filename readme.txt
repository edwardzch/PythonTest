# 自动化测试平台 V2.0

## 项目描述
这是一个基于Python和PySide6构建的高度模块化、可扩展的自动化测试平台。它采用动态插件架构，允许开发人员轻松集成新的硬件驱动和测试功能模块，而无需修改核心代码。平台提供了一个功能丰富的图形用户界面，支持测试序列的创建与编辑、多工位并行测试、系统配置管理、用户权限控制以及强大的诊断工具。

## 主要功能
- **动态插件架构**: 硬件驱动 (`drivers/`) 和测试模块 (`test_modules/`) 在程序启动时动态加载，实现了核心平台与具体测试逻辑的完全解耦。
- **多工位并行测试**: 支持同时运行多个测试工位，每个工位状态独立显示，UI实时更新。
- **图形化序列编辑器**: 提供直观的界面来创建、编辑和保存复杂的测试序列，支持断点调试。
- **集成硬件管理器**: 统一管理所有硬件资源（如程控电源、万用表、串口设备），支持真实硬件和模拟硬件两种模式，方便离线开发和调试。
- **完善的权限管理**: 内置用户登录系统和权限管理界面，可灵活配置不同用户（如管理员、工程师、操作员）的功能访问权限。
- **循环压力测试**: 支持对选定的工位进行长时间、可配置的循环压力测试，并自动生成总结报告。
- **串口抓包工具**: 内置强大的诊断工具，支持实时监控（Live Watch）和后台记录多个工位的串口通信数据，并能自动关联产品SN，生成CSV报告。
- **历史数据分析**: 将测试结果记录到SQLite数据库，并提供一个基于Web的界面来查询和分析历史数据。
- **可深度配置**: 几乎所有系统行为都可通过 `config.json` 进行配置，并提供了配套的图形化配置编辑器。

## 安装
1.  **导航到项目目录:**
    ```bash
    cd C:\Users\edwar\Desktop\PythonTest
    ```
2.  **创建虚拟环境 (推荐):**
    ```bash
    python -m venv .venv
    ```
3.  **激活虚拟环境:**
    *   **Windows:**
        ```bash
        .venv\Scripts\activate
        ```
    *   **macOS/Linux:**
        ```bash
        source .venv/bin/activate
        ```
4.  **安装依赖:**
    ```bash
    pip install -r requirements.txt
    ```

## 使用
1.  **启动应用程序:**
    ```bash
    python main.py
    ```
2.  **登录:**
    *   使用管理员或已授权的用户账户登录。
3.  **加载或创建测试序列:**
    *   通过 "文件" -> "打开序列..." 加载一个现有的 `.json` 序列文件。
    *   通过 "文件" -> "新建序列..." 并使用 "编辑" -> "编辑当前序列..." 打开序列编辑器来创建一个新的测试序列。
4.  **运行测试:**
    *   在主界面的工位上输入产品SN号。
    *   点击 "开始测试" 按钮。测试进度、日志和结果将实时显示在工位界面上。
5.  **使用诊断工具:**
    *   **串口抓包工具:**
        *   访问: "工具" -> "串口抓包工具..."
        *   操作: 勾选要监控的工位，点击 "开始后台记录" 即可将数据保存到 `SnifferReports/` 目录。窗口会实时显示所有通信数据。
    *   **权限管理:**
        *   访问: "工具" -> "权限管理..." (需要管理员权限)
        *   操作: 在此界面添加用户、分配权限。新注册的权限 (如 `access_sniffer_tool`) 会在程序启动时自动添加到列表中。
    *   **历史数据分析:**
        *   访问: "工具" -> "历史数据分析"
        *   操作: 这将启动一个本地Web服务，并在您的浏览器中打开数据分析页面。

## 开发者指南

### 如何新增一个测试模块
1.  在 `test_modules/` 目录下创建一个新的 `.py` 文件。
2.  在该文件中定义您的测试函数。函数可以接受 `config`, `hardware_manager`, `logger` 等由测试引擎自动注入的参数。
3.  为函数编写详细的文档字符串 (docstring)，它将自动出现在软件的 "帮助" 对话框中。
4.  重启应用程序，新的测试模块和函数即可在序列编辑器中选用。

### 如何新增一个硬件驱动
1.  在 `drivers/real/` (真实硬件) 或 `drivers/simulation/` (模拟硬件) 目录下创建一个新的 `.py` 文件。
2.  在文件中实现一个类，该类应包含 `connect`, `close` 以及与硬件交互的方法。
3.  在 `config.json` 中配置该硬件，指定其驱动类名和连接参数。
4.  重启应用程序。`HardwareManager` 将能够根据配置找到并加载您的新驱动。
